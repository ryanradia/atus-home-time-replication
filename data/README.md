# data/

Place your IPUMS ATUS extract here: the data file (`atus_000NN.dat.gz` or `.dat`) **and** its DDI codebook
(`atus_000NN.xml`), with the same base name. See [`../docs/ipums_extract.md`](../docs/ipums_extract.md) for
the exact extract specification.

IPUMS microdata must not be committed or redistributed. Everything in this folder except this README is
excluded by `.gitignore`.
